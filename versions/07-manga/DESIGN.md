# 07 少女漫畫

## 設計概念

把四週年畫成一篇少女漫畫。黑色粗框、網點、對話框和擬聲字，讓心動成為整頁的閱讀節奏。

首屏有四個不等大的漫畫分格，主角跨越網點背景；標題面板、咖啡廳鏡頭與 Q 版對話格各有不同功能。手機依閱讀順序重排為標題、主角、雙格。動畫用快速分格切入與對話框彈出，保留閱讀文字時的安定。

## 視覺與素材

- 色彩：印刷黑 #231920、漫畫紅 #c32147、紙白 #fff8ed。紅黑為角色識別核心，輔色服務於本版藝術方向。
- 字體：主標題使用日系明朝／宋體系統字體，內文使用繁體中文黑體；英文字使用 Georgia 或本版指定字體。
- 實際使用素材：lantern、keyvisual、chibi-smile、picnic、chibi-autumn，均來自使用者提供的雲端資源。副本對照 `../../assets/web-manifest.json`。
- 額外三張角色參考用於配色、星芒、花紋、框飾等設計判讀；未重畫角色或冒稱使用透明官方 Logo。

## 動態與互動

- 標題格與角色格分別以 0.5／0.55 秒快速切入，咖啡與 Q 版格隨後出現，最後彈出音效字與對話框。
- 放射線以 2 秒節奏輕擺；Q 版角色以 1.8 秒節奏上下移動 9px。

本版出場、環境與捲動編排見同目錄 `script.js`，公共控制見 `../../shared/motion.js`。提供動態開關、活動區塊錨點、可展開的活動提醒、複製 TAG、地圖與社群連結。環境動畫在畫面外或頁籤隱藏時暫停。載入與捲動動畫以 transform／opacity 為主。

## 手機與減少動態效果

760px 以下重新排列主視覺與文字，縮小裝飾尺度並停用桌面視差。尊重 `prefers-reduced-motion`：維持完整靜態構圖，關閉 GSAP 演出。圖片或 JS 失效時，活動文字、主要連結與 FAQ 仍可存取。
