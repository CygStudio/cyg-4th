# 11 緋幕手帖

## 設計方向

將 02 的紅幕劇場延伸成整頁的主調，讓中段像攤開在劇院裡的紀念手帖。保留 03 的紙張、照片、便箋與親近感，但統一外圍背景、標題與頁尾的紅黑金語彙。既有 01–10 保留原有設計；頁尾總覽連結統一指向 `../../designs/`。

本輪修正原先「深色首屏、整段米色內容、亮紅頁尾」的斷層：紙色只作為可閱讀、可收藏的實體物件，深色劇場持續包圍這些物件。構圖圍繞熙歌活動插畫、赴約資訊與粉絲的紀念心意。

## 網站入口

本版現為網站首頁 `/`，HTML 以根目錄 `index.html` 為準；本目錄保留樣式、動畫與設計說明。原本的版本網址保留轉址，查詢參數與錨點一併帶至首頁。所有 11 個版本收錄於獨立的 `/designs/`，供內部直接開啟網址比較。首頁與 3D 展場不顯示設計總覽入口；3D 展場的返回活動連結指向首頁。

## 動態與版面

導覽列、紅幕主視覺與「把喜歡貼進日常」跑馬燈合計以 `100dvh` 作為首屏總高度；主視覺高度扣除實際量測的完整導覽與跑馬燈高度。主視覺本身最小高度為桌面 640px、手機 680px；矮視窗可自然捲動，不壓縮標題、日期與操作。角色、拱框與追光隨舞台高度調整。

導覽固定頂部，向下捲動超過 96px 時縮小，回到距頁首 24px 內恢復完整版。兩個方向均以 380ms、power2.inOut 過渡，同步縮放背景、品牌文字與移動連結；每次切換僅量測起訖版面，逐幀只變更 transform 與 opacity。中途反向會從當下畫面接續，調整視窗會重新量測；使用者手動關閉動態時直接呈現最終狀態。原位置保留完整導覽高度，避免切換造成版面跳動。手機縮小品牌區，保留所有導覽連結與動態開關。段落錨點預留縮小導覽高度加 18px，不遮住標題；停用動畫時仍可使用固定導覽。

保留 02 的紅幕、立繪、側標與標題出場時間軸，追光以 7／8 秒節奏往返。照片與紙張沿用現有進場效果。首屏離開可視區域時暫停環境動畫；手動關閉動態時保留完整靜態構圖。

平板優先確保欄寬，活動交通與故事改為直向排列；手機的照片、紙卡與導覽保留安全邊距。600px 以下導覽連結位於品牌下方，3D 展場入口直接可見。頁尾參照 02 的深色背景、暖金文字與星芒，星芒不遮擋文字與操作。

## 手機漢堡選單與抽屜（2026-11-02）

760px 以下以單列品牌與 Lucide 漢堡按鈕呈現導覽；右側抽屜寬度為 88vw、上限 360px，沿用絨幕酒紅至劇場黑背景、古金標題與雙線分隔。桌面維持橫向導覽。共用同一份 nav 節點與動態開關，依斷點移動，不複製連結或偏好狀態；未載入 JavaScript 時仍可使用原有導覽。

抽屜使用原生 modal dialog，鎖定背景捲動並保存位置；支援關閉按鈕、遮罩、Escape、Tab／Shift+Tab 焦點循環。關閉後將焦點交回漢堡按鈕；選擇頁內連結時先解除捲動鎖定，再將焦點與捲動位置交給目標段落。切回桌面時關閉抽屜並將導覽移回 header。

GSAP 僅以 transform 控制右側進出，開啟 480ms、關閉 300ms；手動關閉動畫時立即完成。手機品牌與按鈕維持 44px 操作尺寸，安全區與短螢幕以抽屜內部捲動處理。

## 分層進場與視差（2026-11-02）

首頁進場以 GSAP timeline 分成舞台、角色、邀請三段：拱框與底字建立場景，左右紅幕展開、追光亮起，角色從下方浮現，左右題字與主標題、日期、操作按鈕依序進入。角色仍使用原始完整透明立繪，不宣稱已將人物肢體或服裝拆件。

ScrollTrigger `hero-depth` 將底字、拱框、角色、側邊題字、文案與紅幕分別設定不同捲動位移；手機保留桌面 45% 的幅度，scrub 為 0.65 秒，不固定首屏或攔截一般捲動。角色進場作用於 img，視差作用於 figure；文字進場作用於子項，視差作用於外層，避免共同寫入同一 transform。

抽屜點選頁內選項後先以 300ms 收起，再進行 650–1500ms 的平滑定位，預留縮小導覽高度與 18px 間距。桌面導覽與首屏按鈕共用相同捲動控制；wheel、touchstart 與捲動鍵可中斷。手動關閉動態時直接定位，並移除首屏視差。驗證記錄見 `../../docs/hero-motion-qa.json`。

## 動態預設與開關修正（2026-11-03）

預設開啟，只有明確手動關閉才停用。舊邏輯 `preference.matches || manualOff` 導致系統開啟減少動態時，按鈕無法重新啟用；已移除首屏、導覽、抽屜、平滑捲動及共用 CSS 中的系統強制關閉條件。主要動畫繼續使用 GSAP；不需要更換引擎。

`sessionStorage` 只保留使用者明確選擇；儲存失敗不阻止本頁開關操作。回歸測試 `scripts/qa-motion-preference.py` 在系統減少動態開啟的環境確認預設開啟、雙向切換、重整保留選擇，以及真實的抽屜、首屏視差和平滑捲動。結果見 `../../docs/motion-preference-qa.json`。先前 QA 中「系統減少動態即停用」的驗證屬於已取代的舊需求。
