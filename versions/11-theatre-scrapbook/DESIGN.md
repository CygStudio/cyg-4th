# 11 緋幕手帖

## 組合方向

依本次要求新增版本，既有 01–10 的頁面、樣式與動畫檔保持原樣。

- **導覽與首屏取自 02 緋夜劇場**：深黑導覽列、紅色劇場帷幕、中央立繪、金色拱框、雙側直排題字與追光。header 在本版指導覽列與其下整個紅幕主視覺。
- **首屏之後取自 03 秋日手帖**：原有活動資訊、拍立得照片、周邊資格、提醒、工作名單與頁尾的內容順序和紙張配色。
- 活動資訊下加入一張空間照片卡，連到既有 `../../cafe/` 獨立 3D 展場。導覽列也提供相同入口。


## 視覺規格

首屏採劇場黑 `#130b13`、帷幕紅 `#c32a4c`、暖金 `#d3b271`；內文延續紙白 `#f7eddc`、手帖墨 `#422822`、應援紅 `#bc344c`。深淺轉換標示從演出進入赴約資訊。

首屏使用明朝／宋體與中央對齊，資訊段落沿用 03 的黑體、左對齊與旋轉紙張。新增空間入口也採拍立得、印章與虛線語彙，保持手帖的一致性。

使用 `portrait`、`keyvisual`、`picnic`、`chibi-autumn` 活動插畫，以及 `cafe/assets/preview.webp` 空間模型預覽。來源對照見 `../../assets/web-manifest.json` 與 `../../docs/assets-analysis.md`。

## 動態與手機

沿用 02 的紅幕、立繪、側標與標題出場時間軸，追光以 7／8 秒節奏往返。後續紙張與資訊沿用共用的進場效果。環境動畫在首屏離開可視區域時暫停；動態開關及 `prefers-reduced-motion` 保留完整靜態構圖。

手機保留中央立繪與直向資訊；600px 以下將導覽連結移至品牌下方，動態開關保留在右上角，讓 3D 展場入口無需展開選單即可找到。

## 3D 展場

直接使用專案目前的 Three.js 小驢館頁面，保留五種視角、旋轉、縮放、剖面、描邊與推估區顯示。Landing Page 只載入預覽圖，進入獨立展場後才下載 GLB 與 Three.js。

模型基於公開照片，並非實測或已確認的活動佈置；原有研究說明與限制繼續顯示。展場可返回本版或設計總覽。

## 活動資料與驗證

日期、低消、各品項數量與拿取資格沿用已提供資訊。周邊照片與工作人員／繪師名單仍待補，年份未自行推定。

瀏覽器驗證結果見 `QA.json`。Pages 以專案子路徑部署，需實際確認 CSS、GSAP、Three.js 模組與 GLB 能載入；技術檢查與使用者美術驗收分開記錄。
