# cyg-4th

日本動漫風格的 VTuber 網站設計工作區。

從 [專案美術 brief](docs/art-direction-brief.md) 開始，確認角色、視覺方向、分層素材與動畫分鏡。目前已備妥專案技能與設計 brief；前端框架和網站內容尚待決定。

## 專案技能

技能存放於 `.agents/skills/`，隨儲存庫保存，未安裝至全局目錄。

| 技能 | 用途 |
| --- | --- |
| frontend-design | 美術方向、字體、配色與構圖 |
| gsap-core | 動畫基礎與 easing |
| gsap-timeline | 出場順序、重疊與時間軸 |
| gsap-scrolltrigger | 捲動同步、場景固定與視差 |
| gsap-performance | 動畫效能與實作注意事項 |

技能來源版本與檔案雜湊記錄於 [來源清單](docs/skill-sources.json)，授權資訊見 [第三方聲明](THIRD_PARTY_NOTICES.md)。這些是提供給 agent 的技能文件；網站 runtime 相依套件尚未安裝。
